# Мой Китай — интеграция ИИ для «Справочников»

Версия фронтенда: 1.1.2

## Что уже делает фронтенд
- ☆/★ добавляет любой объект сайта в localStorage `my-china-favorites-v1`.
- Сохраняются: `id`, `type`, `title`, `raw`, `source`, `pretty`, `createdAt`.
- Исходный `raw` никогда не перезаписывается результатом ИИ.
- Кнопка «ИИ · оформить» вызывает `POST https://api.crmuro.ru/api/china-beautify` (сервер — Cloudflare Worker `crmuro-ru-api`, модель DeepSeek, ключ только в секретах воркера).

## Контракт endpoint
POST https://api.crmuro.ru/api/china-beautify
Content-Type: application/json

Вход:
```json
{
  "id": "stable-id",
  "type": "факт",
  "title": "Заголовок",
  "text": "Исходный факт без правок",
  "source": "Библиотека · название книги"
}
```

Выход:
```json
{
  "text": "Короткая, ясная и красиво оформленная формулировка факта."
}
```

## Правила для модели
1. Не добавлять фактов, которых нет во входном тексте.
2. Не менять смысл и числа.
3. Убирать канцелярит, повторы и мусор.
4. 1–3 коротких абзаца или компактная карточка.
5. Если исходник содержит дату, имя, место или число — сохранить их точно.
6. Не выдавать догадки за факты.
7. API-ключ хранить только на сервере/Worker, никогда во фронтенде.

Для Cloudflare удобно реализовать endpoint как Pages Function / Worker route.
