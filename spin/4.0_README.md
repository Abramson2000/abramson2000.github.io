## Что меняется
- Тёплый кремовый интерфейс (стили в `design-4.0.css`).
- Шесть вкладок в порядке: Программа, Теория, Дополнения, Практика, Шпаргалки, Прогресс.
- Компактные карточки программы, исходный текст «О чём эта программа» сохранён.
- Теория: выбор модуля, на телефоне раскрываемый список уроков, сохранение позиции прокрутки.
- Дополнения: вынесены из главной/Теории в отдельную вкладку; реальные данные и исходные идентификаторы уроков не изменены.
- В Практику, личный и административный прогресс, Supabase, авторизацию изменения не вносились.
- Установки дизайна содержат пути к 7 утверждённым фонам, горизонтальному и квадратному логотипам.
- Новая версия PWA-manifest и service-worker: атомарный офлайн-кэш 4.0.

## Обязательная приёмка до merge
1. Открыть сайт в отдельном тестовом окружении. Проверить браузерную консоль и сетевые 404.
2. Проверить на экранах 320, 390, 768, 1280 и 1440 px.
3. Под тестовой учётной записью открыть шесть вкладок, выбор модуля, дополнительный урок, следующую тему и практику.
4. Проверить состояние пользователя после обновления, офлайн/онлайн и синхронизацию на разных устройствах.
5. Проверить администраторскую статистику и права доступа.
6. Подтвердить, что все 7 изображений и PWA-иконки отображаются корректно.
7. Только после этого обсуждать слияние в `main`.

## Путь загрузки утверждённой графики (один ZIP)

В ветку добавлен GitHub Actions `.github/workflows/spin4-asset-import.yml`. Он импортирует ровно 20 файлов из архива с утверждённой графикой, делает commit только в эту ветку и удаляет ZIP после установки.

1. Откройте ветку `feature/spin-4-0-design` в GitHub.
2. Загрузите **один файл** `np40-approved-assets.zip` в каталог `spin/` этой ветки (итоговый путь должен быть `spin/np40-approved-assets.zip`). Не загружайте в `main`.
3. GitHub Actions распакует файлы в `spin/np40/`. Не запускайте merge, пока проверка `SPIN 4.0 preview gates` не станет зелёной.
4. После импорта проведите пользовательские тесты авторизации, офлайн-работы, синхронизации и прогресса. Кодовые проверки не заменяют их.

## Исправления после первичного черновика

- Список «Теории» содержит уроки только выбранного курса; отдельные курсы SPICED, MEDDPICC и ProActive доступны в переключателе по порядку.
- Переходы между вкладками не сбрасывают выбранный урок, а позиция запоминается отдельно для каждого пользователя без изменения облачной схемы прогресса.
- `APP_VER`, PWA manifest и service worker согласованы: 4.0.0.
- В существующем `sw.js` обновлён установщик PWA. Благодаря прежнему URL регистрации активные устройства с 3.3 могут получить новый атомарный кэш после выпуска.
- Добавлены проверки исходников и отсутствующих графических файлов; до загрузки ZIP проверки намеренно блокируют выпуск.
