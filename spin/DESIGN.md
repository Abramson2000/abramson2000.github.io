# DESIGN.md — «Навыки продаж» (crmuro.ru/spin)

Правила оформления интерфейса. Соблюдать при любых правках UI, новых экранах и компонентах. Не заменять токены и не добавлять «премиальные» градиенты, тени и анимации от себя.

## 1. Характер продукта

B2B-тренажёр продаж для медицинских продавцов (СПИН, SPICED, MEDDPICC, ProActive). Тон интерфейса: уверенный, деловой, спокойный — «консультант, а не реклама». Никакой крикливости, никаких стоковых фото, никаких эмодзи в интерфейсе (кроме редких иконок-маркеров в контенте). Весь текст интерфейса — на русском, на «ты» к пользователю не обращаемся («Продолжить урок», не «Ты молодец»).

## 2. Цвета (токены, менять только через :root)

```
--ink:    #15392a   // глубокий тёмно-зелёный: фон сайдбара, тёмные плашки, текст заголовков
--ink-2:  #24533d   // светлее ink: градиент фона экрана входа
--green:  #1c6b47   // фирменный зелёный: акценты, ссылки, прогресс, done-состояния
--lime:   #cbff38   // кислотный лайм: активная навигация, primary-кнопки, ключевые акценты на тёмном
--lime-soft: #eaffad // подложка активных/рекомендательных карточек
--mint:   #e9f4ec   // подложка completed/успешных состояний, чипы
--paper:  #f7faf5   // фон приложения
--white:  #ffffff   // карточки
--line:   #d8e4d9   // все бордеры
--muted:  #6d8075   // вторичный текст
--orange: #ff8d4c   // только для редких предупреждений
--shadow: 0 18px 60px rgba(28,68,48,.09)  // единственная допустимая «большая» тень
--radius: 20px      // базовый радиус карточек
```

Правила:
- Тёмные поверхности: `--ink`, текст на них — белый/`#b7c8bd` (вторичный), акцент — `--lime`.
- Ошибки: НЕ красный-из-палитры — используются тёплые `#d8795e`/`#aa4d32` на подложках `#fff4f0`/`#ffe0d7` (см. .wrong, .difficulty.hard).
- Никаких произвольных цветов «по настроению». Серый текст — только `--muted` или оттенки из семейства ink.

## 3. Типографика

```
font-family: Inter, ui-sans-serif, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif
базовый: 16px, line-height 1.5, -webkit-font-smoothing: antialiased
```

- Заголовки: плотные, отрицательный трекинг. h1 страниц: `clamp(32px, 4vw, 52px)`, line-height 1.04, `letter-spacing: -.045em`. Заголовок главной #program-title: 54px (мобайл 36px). h1 урока: `clamp(36px, 5vw, 60px)`.
- h2 секций: 24–25px, `letter-spacing: -.03em`.
- Крупные цифры-индексы (номер урока, раунд): 92px, weight 950, почти прозрачный ink — декоративный фон карточки.
- Микро-подписи («eyebrow», «kicker»): 10–12px, weight 850–900, `letter-spacing: .08–.13em`, ВЕРХНИЙ РЕГИСТР, цвет `--green` (на тёмном — `--lime`).
- Вторичный текст: 13px, `--muted`.
- Числа/счётчики: tabular по духу, weight 800–950, плотный трекинг.

## 4. Сетка и отступы

- Десктоп: сайдбар 260px фиксированный + контент; контент `max-width: 1280px`, паддинги `44px 4.5vw 64px`.
- Карточки уроков: `grid-template-columns: repeat(4, 1fr)`, gap 14px. Брейки: 1050px → 2 колонки; 760px → 1 колонка.
- Экран урока: `270px (rail) + gap clamp(35px, 6vw, 90px) + 760px` (контент), по центру.
- Тренажёр: 2 колонки `.83fr 1.17fr`.
- Базовый шаг отступов кратен 2 (8/10/12/14/16/18/20/24/28…). Вертикальные секции: 26–42px.

## 5. Компоненты

### Кнопки (radius 12, padding 13px 18px, weight 800)
- **Primary**: фон `--lime`, текст `--ink`. Hover: translateY(-2px) + мягкая тень `rgba(115,159,0,.2)`. Disabled: opacity .45, cursor not-allowed.
- **Secondary**: белая, бордер `--line`; hover — бордер `--green`.
- **Dark**: фон `--ink`, текст белый; hover — `#0d2c20`.
- Кнопки-«пилюли» (фильтры, сегменты): radius 999px, активная — фон `--ink`, текст белый.

### Карточки
- База: белая, бордер `--line` 1px, radius 16–20px. Hover-подъём: translateY(-3px) + `--shadow` (только у кликабельных).
- **module-card** (урок): min-height 260px (мобайл 220px), padding 22px, декоративный номер-призрак справа сверху.
  - current: бордер 2px `--green`, лёгкая тень;
  - completed: фон `--mint`;
  - locked: opacity .6, saturate(.6), cursor not-allowed.
- **scenario-card** (левая часть тренажёра): тёмная (`--ink`), реплика клиента в blockquote 24–36px weight 760, белая плашка-контекст на rgba(255,255,255,.05).
- Плавный переход: `.2s ease`, transform/box-shadow/background/border-color.

### Прочее
- Аватар: круг 38px, фон `#f3d18c`, текст `#513e19`.
- Чекбокс «урок изучен»: квадрат 23px, checked — `--green` + белая галочка.
- Шпаргалки: аккордеон (`.cheat-item`), открытая строка — фон `--mint`, номер-кружок заливается `--lime`.
- Тосты: снизу справа, фон `--ink`, белый текст, radius 12, `--shadow`.
- Модалки: бекдроп rgba(6,25,17,.68) + blur(7px), карточка radius 22, анимация .25s.
- Прогресс-бары: высота 4–8px, radius 999px, трек `--line`/`--mint`, заполнение `--green`.

## 6. Адаптив

- ≤1050px: сайдбар 210px, сетки 4→2 колонки.
- ≤760px: сайдбар скрыт → нижняя мобильная навигация (78px, 5 вкладок, blur-подложка); заголовки 36px; сетки в 1 колонку; rail урока превращается в горизонтальную ленту номеров (5 в ряд); кнопки на всю ширину где нужно.
- ≤420px: ещё компактнее паддинги, xp-pill ужимается.
- `prefers-reduced-motion: reduce` — отключать все анимации/переходы.

## 7. Запреты для агентов

- Не добавлять градиенты сверх двух существующих (фон входа radial ink→ink-2; лёгкие 135° бело-мятные подложки .about-card/.cloud-m).
- Не вводить новые цвета, тени, радиусы «покрасивее» — только через токены.
- Не менять шрифт (Inter-стек) и не подключать внешние шрифты/иконки без спроса.
- Не переписывать существующие классы «на современный лад» — правки точечные, регресс по ключевым экранам обязателен.
- Не добавлять английский текст в интерфейс.
