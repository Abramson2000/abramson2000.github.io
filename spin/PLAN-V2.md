## Мета-модель (сердце v2)

**Формула: ПРОБЛЕМА → ИНСАЙТ → РЕШЕНИЕ → ЦЕННОСТЬ → ДВИЖЕНИЕ К СДЕЛКЕ**

| Ситуация в разговоре | Включить | Задача |
|---|---|---|
| «У нас всё нормально», не видит проблему | СПИН (P→I→N) | Осознать проблему |
| Видит неверно / не понимает причину | Challenger | Переосмыслить (инсайт+цифры) |
| Нужно комплексное решение, много участников | Solution | Спроектировать решение |
| Сводит к цене, «дорого» | Consultative | Доказать ROI |
| Сделка зависла, нет движения | ProActive | Карта закупки + следующий шаг |

## Новая структура курса (предварительно)

- **Модуль 0. Карта продавца**: 5 инструментов одним взглядом, формула, таблица выбора, сквозной процесс. (Новый контент.)
- **Модуль 1. СПИН** (существует, доработать): S→P→I→N, скрытая→явная потребность (8 шагов Eduson), F/A/B, обязательство, Снайдер (4 инструмента ценности, 5 финпоказателей, склонность к подтверждению).
- **Модуль 2. Challenger**: 6 шагов (разогрев → переосмысление → разум → эмоции → будущее → решение); гипотеза вместо открытых вопросов. (Новый; книги Диксона.)
- **Модуль 3. Solution**: карта болей, диагноз, критерии идеального решения, ЛПР-система, план оценки, закрытие через value proposition. (Новый; книги Идса.)
- **Модуль 4. Consultative**: норма, перевод в деньги, ROI на данных клиента, малый проект, постоянные улучшения. (Новый; книги Хэнана.)
- **Модуль 5. ProActive**: карта закупки, каждый контакт = следующий шаг, обратный отсчёт от цели клиента, план реализации, закрытие. (Новый; книги Миллера.)
- **Модуль 6. Тренажёр переключения**: реплика/ситуация → выбрать методику и ход; смена тактики внутри диалога (то, что просил Саша: «менять подход прямо во время разговора»).
- **Кейсы**: 3 существующих (СПИН-центр) + новые под каждую методику + «смешанные» (начал СПИНом → клиент сводит к цене → переключился на Consultative/Challenger).
