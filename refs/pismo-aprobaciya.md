— набор приходит стерильным и готовым, собирать и обрабатывать нечего;

Что прошу взамен — только информацию. Короткий протокол на пять параметров по каждой процедуре: время морцелляции, объём удалённой ткани, осложнения, замечания по удобству, общее впечатление хирурга. Заполняется оперирующим врачом, две-три минуты после операции. Форму пришлю заранее.

Если по итогу скажете «не наше» — на этом и закончим. Вы ничего не должны.

## Протокол апробации (приложение)

Фиксируется по каждой процедуре:

1. Дата, хирург, объём железы по УЗИ
2. Время энуклеации и время морцелляции отдельно
3. Масса удалённой ткани
4. Осложнения (перфорация, кровотечение, заклинивание лезвия)
5. Замечания по удобству: сборка, вес, эргономика, обзор
6. Общее впечатление: «взял бы в работу / нет / при условии»

Итог апробации — одна страница на клинику.
