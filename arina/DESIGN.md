# DESIGN.md — «Тингли» (crmuro.ru/tingli)

Правила оформления интерфейса тренажёра китайского языка. Соблюдать при любых правках UI, новых экранах и компонентах. Не заменять токены и не добавлять «премиальные» градиенты, тени и анимации от себя.

## 1. Характер продукта

Учебное приложение для отработки китайского: словарь, уроки, иероглифика (письмо), аудио, избранное. Тон: тёплый, спокойный, «бумажный» — как рабочая тетрадь. Интерфейс на русском, китайский текст — только контент (иероглифы, пиньинь, переводы). Акцент — красный, но в малых дозах: ошибки, активные состояния, иероглифические маркеры. Никаких фотостоков и декоративного мусора.

## 2. Цвета (токены, менять только через :root)

```
--bg:        #f5f4f1   // тёплый бумажный фон приложения
--card:      #ffffff   // карточки
--text:      #1d1d21   // почти чёрный текст
--muted:     #8f8f97   // вторичный текст
--faint:     #b9b9c0   // третичный/подписи
--red:       #c23a2b   // китайский красный: акцент, ошибки, активное
--red-deep:  #a52e21   // hover/нажатие красного
--red-soft:  #fbece9   // подложка ошибок/красных состояний
--ok:        #1f9d55   // верно/успех
--ok-soft:   #e8f6ee   // подложка успеха
--bad:       #d64545   // жёсткая ошибка
--bad-soft:  #fdeeee   // подложка жёсткой ошибки
--yellow:    #ffd93d   // редкие акценты (бейджи, звёзды)
--black:     #1d1d21   // тёмные поверхности
--shadow-card: 0 1px 2px rgba(29,29,33,.05), 0 8px 24px rgba(29,29,33,.06)
--shadow-pop:  0 2px 6px rgba(29,29,33,.08), 0 14px 34px rgba(29,29,33,.1)
```

Правила:
- Верно/неверно: зелёный `--ok` на `--ok-soft`, красный `--bad`/`--red` на мягких подложках. Красный — НЕ «тревога», а рабочий акцент языка.
- Фон приложения всегда тёплый `--bg`, белые карточки на нём. Тёмные плашки — только `--black`-семейство.
- Никаких синих ссылок/кнопок: синий в палитре отсутствует намеренно.

## 3. Типографика

```
латиница/кириллица: -apple-system, BlinkMacSystemFont, "Segoe UI", Arial, sans-serif (16px база)
иероглифы: "SimSun", "Songti SC", "STSong", serif — 宋体 (печатный стиль, для крупных иероглифов уроков и письма)
пиньинь: системный sans, с тонами через диакритику (не цифры!)
```

- Иероглиф в уроке — крупный (80–120px+), serif-семейство, цвет `--text`.
- Заголовки экранов: 20–24px, плотные; мелкие подписи 11–12px `--muted`/`--faint`.
- Подписи пиньиня под иероглифами — `--muted`, без засечек.
- Никаких декоративных рукописных шрифтов для контента (для иероглифов письма — эталонный штрих, не шрифт).

## 4. Компоненты

- **Карточки**: белые, radius 14–18px, `--shadow-card` (тихая). Pop-слои/модалки: `--shadow-pop`, radius 17–18px.
- **Кнопки**: `.btn` — скругление 14px, жирный текст; пилюли/чипы — radius 99/999px. Primary-действия — красный `--red`/белый текст (hover `--red-deep`); нейтральные — белые с бордером.
- **Вкладки-табы**: пилюли 99px, активная — заливка (красная или тёмная), неактивная — приглушённая.
- **Поле ввода**: белое, бордер 1px `--faint`/серый, radius 14px, крупный текст (для иероглифов — serif).
- **Проверка ответов**: мгновенная подсветка: верный — `--ok` + `--ok-soft` фон, неверный — `--bad`/`--red` + мягкая подложка; короткая анимация «встряски» только при ошибке (не чаще 1 раза за проверку).
- **Прогресс/полосы**: тонкие (4–6px), radius 999px, заполнение `--ok` или `--red` (в зависимости от семантики).
- **Аудио-кнопка**: круглая (50%), заметная, с иконкой; активное воспроизведение — подсветка.
- **Бейджи**: счётчики (например, избранное, ошибки) — скругление 99px, компактные.

## 5. Адаптив

- Одна колонка на мобильном, карточки на всю ширину с паддингами 16–20px; крупные иероглифы масштабируются (clamp/визуальный размер), но остаются «главными» на экране урока.
- Нижние экраны/табы — фиксированные, высота ~64–78px, с блюром подложки при скролле.

## 6. Запреты для агентов

- Не добавлять новые цвета (особенно синий), градиенты, тени и радиусы «покрасивее» — только через токены.
- Не менять шрифты: системный sans + SimSun/Songti для иероглифов; не подключать внешние веб-шрифты без спроса.
- Не переводить интерфейс на английский и не добавлять англ. подписи.
- Не переписывать существующие классы «на современный лад» — правки точечные, регресс по ключевым экранам (словарь, урок, письмо, избранное) обязателен.
